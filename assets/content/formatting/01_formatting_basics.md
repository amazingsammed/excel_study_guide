# Formatting Basics

Formatting changes how cells **look** without changing their values. Good
formatting makes data easier to read and understand.

## The Home tab

Most formatting lives on the **Home** tab:

| Group | Commands |
| --- | --- |
| Font | Font, size, bold, italic, underline, colour |
| Alignment | Left, centre, right, wrap text, merge |
| Number | Currency, percent, decimal places |
| Styles | Cell styles, conditional formatting |
| Cells | Insert, delete, format |

## Alignment

| Button | Effect |
| --- | --- |
| Left align | Text pushed to the left |
| Centre | Content centred |
| Right align | Content pushed right |
| Wrap Text | Long text wraps inside the cell |
| Merge & Center | Joins cells and centres the content |

**Wrap Text** keeps long labels visible without widening the column. Increase the
row height afterwards so all lines show.

## Row height and column width

- Drag the boundary between two column letters or row numbers.
- Double-click the boundary to **auto-fit** to the widest entry.
- Select several columns, then drag one boundary to resize them all.

## Copying formats

Use the **Format Painter** to copy formatting from one cell to another (see the
next chapter).

## Key takeaways

- Formatting changes appearance, not values.
- Wrap Text and auto-fit keep sheets tidy.
- The Home tab holds the formatting you will use most.

> **Practice:** Type a long sentence in a cell, turn on **Wrap Text**, then
> auto-fit the column width.
