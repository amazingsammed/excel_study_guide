# Editing Cells

This chapter covers moving, adding, deleting, and undoing changes to cells.

## Moving cells

- **Cut and paste:** `Ctrl + X`, select a destination, `Ctrl + V`.
- **Drag and drop:** select the border of the cell and drag it to a new spot.
- **Insert:** right-click a row or column header and choose **Insert**.

## Adding cells, rows and columns

| Action | How |
| --- | --- |
| Insert row | Right-click row header > Insert |
| Insert column | Right-click column header > Insert |
| Insert cells | Right-click a cell > Insert > Shift cells right/down |
| Keyboard | `Ctrl + Shift + +` inserts based on the selection |

## Deleting cells

Right-click and choose **Delete**, then pick how to shift the remaining cells:

- Shift cells left
- Shift cells up
- Entire row
- Entire column

> Note: pressing `Delete` clears the **contents** only. Right-click > **Delete**
> removes the cell itself and shifts the rest.

## Undo and redo

| Shortcut | Action |
| --- | --- |
| `Ctrl + Z` | Undo the last action |
| `Ctrl + Y` | Redo |
| `F4` | Repeat the last action |

Excel keeps a history of recent actions, so you can undo several steps in a row.

## Key takeaways

- `Delete` clears content; **Delete** from the menu removes the cell.
- Inserting a row pushes data down; inserting a column pushes data right.
- `Ctrl + Z` and `Ctrl + Y` are your safety net.

> **Practice:** Type data in `A1:A3`, right-click row `2` and insert a row. Then
> press `Ctrl + Z` to undo it.
