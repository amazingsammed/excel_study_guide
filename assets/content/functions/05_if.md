# IF

`IF` returns one value when a condition is true and another when it is false. It
is the foundation of decision-making in Excel.

## Syntax

```
=IF(logical_test, value_if_true, value_if_false)
```

## Examples

| Formula | Result |
| --- | --- |
| `=IF(A1>10,"High","Low")` | High if A1 is above 10 |
| `=IF(A1="","Blank","Filled")` | Check for empty cell |
| `=IF(A1>=60,"Pass","Fail")` | Pass or fail |

## Nesting IF

Chain conditions by putting another `IF` in the false branch.

```
=IF(A1>=90,"A",IF(A1>=80,"B",IF(A1>=70,"C","F")))
```

Nesting gets hard to read, so newer Excel offers `IFS`:

```
=IFS(A1>=90,"A", A1>=80,"B", A1>=70,"C", TRUE,"F")
```

## Combining with AND / OR

```
=IF(AND(A1>=60,B1>=60),"Pass","Fail")
=IF(OR(A1="Yes",B1="Yes"),"Approve","Review")
```

## IF with text and calculations

```
=IF(A1>0, A1*0.1, 0)
=IF(B1="", "Missing", B1*2)
```

## Errors to watch for

- Text results must be in quotes: `"Pass"`, not `Pass`.
- Use commas to separate the three arguments.
- `#NAME?` usually means a missing quote.

## Key takeaways

- `IF` = test, result if true, result if false.
- Nest `IF` or use `IFS` for multiple outcomes.
- `AND` / `OR` let you test several conditions at once.

> **Practice:** In `B1` write `=IF(A1>=50,"Pass","Fail")` and test it with values
> above and below 50.
