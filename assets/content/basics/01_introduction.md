# Introduction to Excel

Excel is a **spreadsheet program** made by Microsoft. A spreadsheet is a grid of
rows and columns that stores data and calculates results from it. Excel is one of
the most widely used tools in the world for working with numbers, lists, and
reports.

## What Excel is used for

| Area | Typical use |
| --- | --- |
| Data analysis | Summarising, filtering and charting data |
| Finance & accounting | Budgets, invoices, loan and interest calculations |
| Project management | Task lists, timelines, progress tracking |
| Reporting | Dashboards and printable summaries |
| Personal use | Shopping lists, planners, expense tracking |

## The building blocks

- **Workbook** – the file you save (for example `budget.xlsx`).
- **Worksheet (sheet)** – a single page inside a workbook. A workbook can hold many sheets.
- **Cell** – the intersection of a row and a column, such as `A1`.
- **Row** – numbered horizontally (`1`, `2`, `3`, ...).
- **Column** – labelled with letters vertically (`A`, `B`, `C`, ...).
- **Range** – a group of cells, such as `A1:C10`.

## Why learn Excel

1. It turns raw data into answers.
2. Formulas update automatically when data changes.
3. The same skills transfer to Google Sheets, LibreOffice Calc, and Excel Online.

## Key takeaways

- Excel stores data in cells arranged in rows and columns.
- Formulas and functions let you calculate instead of typing results by hand.
- Everything you learn here works offline in the desktop app.
