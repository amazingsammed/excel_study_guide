# Charts

A chart turns numbers into a picture, making patterns and comparisons obvious at
a glance.

## Creating a chart

1. Select the data (including headers).
2. Go to **Insert > Charts**.
3. Choose a chart type.

## Choosing a chart type

| Chart | Best for |
| --- | --- |
| Column / Bar | Comparing categories |
| Line | Trends over time |
| Pie | Parts of a whole (few slices) |
| Scatter | Relationship between two numbers |
| Area | Trend plus magnitude |
| Radar | Comparing several variables |

## Chart elements

| Element | Purpose |
| --- | --- |
| Chart Title | Describes the chart |
| Axis Titles | Label the X and Y axes |
| Legend | Explains the series colours |
| Data Labels | Show the value on each point |
| Gridlines | Help read values |

Add or remove these with the **+** button next to a selected chart.

## Changing the data

- **Select Data** – add or remove series and change the category axis.
- **Switch Row/Column** – swap what is plotted on each axis.

## Formatting a chart

- **Chart Styles** give instant colour and layout presets.
- Right-click any element and choose **Format** for detailed control.
- Keep charts simple: one message per chart.

## Sparklines

**Insert > Sparklines** puts a tiny trend line inside a single cell – great for
dashboards.

## Key takeaways

- Match the chart type to the question you are answering.
- A clear title and labelled axes make a chart self-explanatory.
- Pie charts work best with only a few slices.
