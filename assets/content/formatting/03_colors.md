# Colors

Colour is used to make headers stand out, group related data, and highlight
important results.

## Where to apply colour

| Type | Applies to |
| --- | --- |
| Font Color | The text or numbers |
| Fill Color | The cell background |
| Border Color | The cell outline |

All three are on the **Home** tab in the Font group.

## Using theme colours

Excel offers a **theme palette**: a set of coordinated colours that update
together if you change the workbook theme. Using theme colours keeps a
spreadsheet looking consistent.

- **Theme Colors** – change with the theme.
- **Standard Colors** – fixed set of common colours.
- **More Colors** – pick any custom colour.

## Copying a colour

Use the **eyedropper** in the colour menu to sample a colour from anywhere on
screen, including another cell.

## Best practices

1. Use a light fill for headers and a darker font for contrast.
2. Keep the palette small – two or three colours is usually enough.
3. Avoid red and green together to stay colour-blind friendly; add bold or a
   symbol as a second cue.

## Key takeaways

- Font colour, fill colour and border colour are separate settings.
- Theme colours keep a workbook consistent.
- Colour should support the data, not distract from it.

> **Practice:** Give a header row a dark fill with white text, then use the
> Format Painter to repeat the style on another sheet.
