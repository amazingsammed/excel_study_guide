# Format Painter

The **Format Painter** copies formatting (colour, font, borders, number format)
from one cell or range to another. It is one of the biggest time-savers in Excel.

## Using it

1. Select the cell that already has the formatting you want.
2. On the **Home** tab, click **Format Painter** (the paintbrush icon).
3. Click or drag over the cells you want to format.

The brush is dropped after one use.

## Applying to several places

**Double-click** the Format Painter button to keep it active, then click as many
cells as you like. Press `Esc` when finished.

## What it copies

| Copies | Does not copy |
| --- | --- |
| Font, size, colour | The cell's value |
| Fill colour | Column width |
| Borders | Row height |
| Number format | Comments |
| Alignment | Data validation |

## Keyboard shortcut

There is no default shortcut, but you can add one. A quick workaround is to copy
the source cell (`Ctrl + C`), then use **Paste Special > Formats** on the target.

## Key takeaways

- Format Painter copies appearance only, never the data.
- Double-click the button to paint multiple areas.
- Paste Special > Formats is the keyboard-friendly alternative.

> **Practice:** Format one cell with a bold font, a fill colour and a border, then
> use the Format Painter to copy that look to five other cells.
