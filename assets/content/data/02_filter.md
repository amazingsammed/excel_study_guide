# Filter

Filtering hides rows that do not match criteria, letting you focus on a subset of
your data without deleting anything.

## Turning on filters

1. Click inside your data.
2. Go to **Data > Filter** (`Ctrl + Shift + L`).
3. Dropdown arrows appear in the header row.

## Using a filter

1. Click a column's arrow.
2. Tick the values you want, or use **Number Filters** / **Text Filters**.
3. Click OK – only matching rows remain visible.

## Filter options

| Type | Examples |
| --- | --- |
| Text filters | Equals, Contains, Begins with |
| Number filters | Greater than, Between, Top 10 |
| Date filters | Before, After, This month |
| Colour filters | Filter by fill or font colour |

## Combining filters

Each column has its own filter, and they combine with **AND**. For example,
filter `Region = North` **and** `Sales > 1000` to see only high sales in the
north.

## Clearing filters

- Click **Clear Filter** in a column menu to reset one column.
- **Data > Clear** removes all filters.

## Key takeaways

- Filters hide rows; they never delete data.
- `Ctrl + Shift + L` toggles filters on and off.
- Multiple column filters combine with AND.

> **Practice:** Add a filter to a table of products and show only rows where the
> price is greater than 50.
