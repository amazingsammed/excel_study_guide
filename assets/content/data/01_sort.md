# Sort

Sorting arranges rows in order based on the values in one or more columns.

## Quick sort

1. Click a cell inside your data.
2. On the **Data** tab, click **A > Z** (ascending) or **Z > A** (descending).

Excel automatically detects the surrounding table and sorts whole rows, keeping
each record together.

## Custom sort

Use **Data > Sort** for more control:

1. Choose the **column** to sort by.
2. Choose the **order**: A to Z, Z to A, or a custom list.
3. Add **levels** to sort by more than one column.

## Multi-level sort example

To sort a sales list by region, then by sales descending:

| Level | Sort by | Order |
| --- | --- | --- |
| 1 | Region | A to Z |
| 2 | Sales | Largest to smallest |

## Sorting by colour or icon

The Sort dialog can sort by cell colour, font colour, or conditional formatting
icon. This is useful when colour carries meaning.

## Common mistakes

- Sorting only one column instead of the whole table, which scrambles records.
- Sorting text that looks like numbers (for example `'001`).
- Forgetting that formulas referencing the data may break if rows move.

## Key takeaways

- Sort whole records, not single columns.
- Use multiple levels for meaningful order.
- The Sort dialog also handles colour and custom lists.

> **Practice:** Build a small table of names and scores, then sort by score from
> largest to smallest.
