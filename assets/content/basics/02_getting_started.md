# Getting Started

This chapter walks through the Excel window and the basic actions you perform
before writing formulas.

## The Excel window

| Part | What it does |
| --- | --- |
| Ribbon | Tabs (Home, Insert, Data, ...) that hold commands |
| Formula Bar | Shows and edits the contents of the active cell |
| Name Box | Shows the address of the active cell or selected range |
| Column headers | Letters `A`, `B`, `C`, ... |
| Row headers | Numbers `1`, `2`, `3`, ... |
| Sheet tabs | Switch between worksheets at the bottom |
| Status bar | Quick totals and counts for a selection |

## Entering data

1. Click a cell to make it active.
2. Type a value or text.
3. Press `Enter` to move down, or `Tab` to move right.

Excel treats your input differently depending on what it looks like:

| You type | Excel treats it as |
| --- | --- |
| `123` | Number (right-aligned) |
| `Hello` | Text (left-aligned) |
| `=1+1` | Formula (starts with `=`) |
| `2026-01-15` | Date |

## Opening, saving and new workbooks

- `Ctrl + N` – new workbook
- `Ctrl + O` – open a workbook
- `Ctrl + S` – save
- `F12` – Save As

## Useful first shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl + Z` | Undo |
| `Ctrl + Y` | Redo |
| `Ctrl + C` / `Ctrl + V` | Copy / Paste |
| `Ctrl + B` / `Ctrl + I` | Bold / Italic |
| `Ctrl + Home` | Jump to `A1` |
| `Ctrl + Arrow` | Jump to the edge of a data block |

## Key takeaways

- The formula bar always shows the *real* contents of a cell.
- Numbers align right, text aligns left – a quick way to spot mixed data.
- Any calculation must begin with `=`.

> **Practice:** Create a new workbook, type `10` in `A1` and `20` in `A2`, then in
> `A3` type `=A1+A2` and press Enter. You should see `30`.
