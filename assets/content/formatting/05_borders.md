# Borders

Borders draw lines around and between cells. They are the standard way to give a
table structure.

## Border options

| Border | Effect |
| --- | --- |
| Bottom Border | Line under the cell |
| Top Border | Line above the cell |
| Left / Right Border | Line on one side |
| All Borders | Lines around every selected cell |
| Outside Borders | A box around the whole selection |
| Thick Box Border | Heavier outline |
| No Border | Removes borders |

Find them under **Home > Borders** (the grid icon).

## Drawing borders

1. Select the range.
2. Open the **Borders** dropdown.
3. Choose a preset such as **All Borders**.

For full control, open **Format Cells** (`Ctrl + 1`), go to the **Border** tab and
choose line style and colour before clicking the diagram.

## Gridlines versus borders

- **Gridlines** are the faint lines shown on screen. They do not print by default.
- **Borders** are real formatting and always print.

Turn gridlines off with **View > Gridlines** to see your borders more clearly.

## Best practices

- Use a single line style consistently.
- Avoid borders on every cell – use them to separate sections.
- A thick outside border plus thin inside lines looks professional.

## Key takeaways

- Borders print; gridlines usually do not.
- `Ctrl + 1` opens the Format Cells dialog for precise control.
- Use borders to structure tables and reports.

> **Practice:** Select a 3x3 block and apply **All Borders**, then change the
> outside to a thick border.
